# QA v2 acceptance demo — bad overlay FAIL → deterministic repair → PASS

Self-contained, offline, ~10 s. One command: `artifacts/p2/qa/run_demo.sh`
(from the repo root; it also works from any cwd because it resolves the repo).

## What is real and what is demo-only

* **Real footage:** the first 4 s of `tests/fixtures/clips/fx_pd_real_16x9_a`
  (1280×720, 30 fps, public-domain US Government video), re-encoded to
  `base_clip.mp4` (audit: `base_sha256` in `perception_demo.json`).
* **Deliberately bad overlay:** a 340×340 box with the text `QA CHECK`, painted
  over the face with Pillow for frames 30–74 (`build_demo.py`), then H.264
  encoded. This simulates the v1 failure mode: the box is inside the canvas and
  avoids nothing, and v1 face-box logic alone would not have known how much of
  the hair/shoulders it covered.
* **Demo masks (NOT perception-module output):** generated by
  `scripts/build_demo.py` from Apple Vision (person segmentation + face
  detection) at 5 Hz. The document's `backend.name` is
  `qa-demo-vision-helper`, `capabilities.person_mask = true`, masks are 1/4-scale
  PNGs and paths are relative to the JSON — the same shape as
  `docs/PERCEPTION-CONTRACT.md`. They are **not** `src/semotion/perception.py`
  output and must not be cited as such. `existing_text` is empty in this demo
  (the helper does not OCR), so `existing_text_collision` is `NOT RUN`; the real
  v2 render passes that check with 1 protected region.
* **Demo overlay/ink passes:** the painter also writes an overlay-only pass
  (element layer over black) and an ink-only pass (glyphs only over black), so
  footprint, `displayed_text` and `text_onset` can be measured exactly.

## Pipeline (see `run_demo.sh`)

```
build_demo.py prep                         # base clip + perception_demo.json + motion_ir_bad.json
build_demo.py paint --ir motion_ir_bad     # final_bad.mp4 + overlay_bad.mp4 + ink_bad.mp4
verify2 ... --out qa_bad/qa_metrics.json   # expected exit 1 (FAIL)
repair.py ... --out-dir repair             # motion_ir.repaired.json + repairs.json
build_demo.py paint --ir repaired --repeats 2
                                           # final_fixed.mp4 + final_fixed_run2.mp4 + passes
verify2 ... --second-render ... --out qa_fixed/qa_metrics.json   # expected exit 0 (PASS)
repair.py ... repaired IR + stale metrics  # idempotence: noop=true, IR bytes identical
```

## Repair — what changed and why

`artifacts/p2/qa/repair/repairs.json`:

* element `el_demo`: `relocate` — box `[500,90,340,340]` → `[114,32,340,340]`
  (zone `background`), font 64 unchanged, window unchanged.
* reason: footprint touched the person/face. Evidence: assessment measured
  **5,444 person-mask pixels** under the old box on the 1/4 mask grid, plus a
  face-box intersection.
* IR is resealed (`provenance.ir_sha256`) and validates.
* **Idempotence:** running repair again on the repaired IR with the *stale* bad
  metrics gives `noop=true`, `repairs=[]`, and byte-identical IR (see
  `repair/idempotence/`).

## Exact commands (manual form)

```bash
export PYTHONPATH=src
PY=.venv/bin/python
$PY artifacts/p2/qa/scripts/build_demo.py prep
$PY artifacts/p2/qa/scripts/build_demo.py paint \
  --ir artifacts/p2/qa/motion_ir_bad.json --out artifacts/p2/qa/final_bad.mp4 \
  --overlay-out artifacts/p2/qa/overlay_bad.mp4 --ink-out artifacts/p2/qa/ink_bad.mp4
$PY -m semotion.verify2 --ir artifacts/p2/qa/motion_ir_bad.json \
  --source artifacts/p2/qa/base_clip.mp4 --final artifacts/p2/qa/final_bad.mp4 \
  --overlay artifacts/p2/qa/overlay_bad.mp4 --ink-only artifacts/p2/qa/ink_bad.mp4 \
  --perception artifacts/p2/qa/perception_demo.json \
  --out artifacts/p2/qa/qa_bad/qa_metrics.json            # exit 1, FAIL
$PY -m semotion.repair --ir artifacts/p2/qa/motion_ir_bad.json \
  --metrics artifacts/p2/qa/qa_bad/qa_metrics.json \
  --masks artifacts/p2/qa/perception_demo.json --out-dir artifacts/p2/qa/repair
$PY artifacts/p2/qa/scripts/build_demo.py paint \
  --ir artifacts/p2/qa/repair/motion_ir.repaired.json --out artifacts/p2/qa/final_fixed.mp4 \
  --overlay-out artifacts/p2/qa/overlay_fixed.mp4 --ink-out artifacts/p2/qa/ink_fixed.mp4 --repeats 2
$PY -m semotion.verify2 --ir artifacts/p2/qa/repair/motion_ir.repaired.json \
  --source artifacts/p2/qa/base_clip.mp4 --final artifacts/p2/qa/final_fixed.mp4 \
  --overlay artifacts/p2/qa/overlay_fixed.mp4 --ink-only artifacts/p2/qa/ink_fixed.mp4 \
  --perception artifacts/p2/qa/perception_demo.json \
  --second-render artifacts/p2/qa/final_fixed_run2.mp4 \
  --out artifacts/p2/qa/qa_fixed/qa_metrics.json          # exit 0, PASS
```

## Limits of this demo

* The masks are demo-only (see above); the real perception document is consumed
  unchanged by `verify2` (see `artifacts/p2/qa/final_zq/`).
* The demo clip has no burned-in text and no scrim backdrop, so those two checks
  are `NOT RUN` here. Their negative controls live in `tests/test_verify2.py`
  (synthetic text region → FAIL; scrim over person → FAIL), and the real v2 run
  exercises both (0 px overlap, contrast 7.28–12.23).
* The demo paints one element; collision/footprint-collision checks are
  exercised by the synthetic tests and the 5-element v2 render.
